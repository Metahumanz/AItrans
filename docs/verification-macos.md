# macOS 端验证清单

> 用途：在 Mac 上按此逐项勾选。状态：App 已能构建、打包、启动，但尚未逐项人工验收。

## 0. 环境

- [ ] macOS 14 或更新版本
- [ ] Xcode 命令行工具可用（`swift --version` 能输出 6.0+）

## 1. 构建与启动

```sh
cd macos
swift test
../macos/Scripts/package-app.sh 0.1.0
open dist/AITrans.app
```

- [ ] 测试全绿（当前 40 个）
- [ ] 打包生成 `macos/dist/AITrans.app` 与 zip
- [ ] 双击启动后出现主窗口，菜单栏显示 AITrans
- [ ] 首次启动若被 Gatekeeper 拦截，右键「打开」或到「隐私与安全性」放行后可用
- [ ] 关闭窗口后进程退出（Dock 图标消失）

## 2. 输入

- [ ] 拖拽 `.srt` 文件到列表
- [ ] 拖拽文件夹到列表（自动收集其中的 SRT）
- [ ] 「添加文件」选择器可用
- [ ] 「添加文件夹」选择器可用
- [ ] 粘贴路径（含 `~`）后回车可添加
- [ ] 不存在的路径给出提示
- [ ] 重复添加同一文件不会出现两条
- [ ] 超过 200 个文件时截断并提示

## 3. 编码与解析

用 `fixtures/srt/` 里的样本，或自备字幕：

- [ ] UTF-8 正常
- [ ] UTF-8 带 BOM 正常（首行无多余字符）
- [ ] UTF-16 LE 带 BOM 正常
- [ ] GBK / GB18030 中文正常
- [ ] CRLF 换行正常
- [ ] 多行字幕保持换行
- [ ] 畸形块（缺正文）原样保留，不报错

## 4. 输出

- [ ] 源目录模式生成 `原名_translated.srt`，不覆盖原文件
- [ ] 应用输出目录模式（`~/Library/Application Support/AITrans/output`）
- [ ] 自定义目录模式
- [ ] 后缀含 `/` `:` 等非法字符时被拒绝并提示
- [ ] 两个源文件会撞同一输出时提前报错
- [ ] 「强制重新处理」覆盖已有输出；不勾选时跳过非空输出
- [ ] 「打开输出目录」能打开访达

## 5. 引擎与网络

- [ ] API 提供商：只翻译
- [ ] API 提供商：翻译 + 润色
- [ ] 断网时重试后给出可读错误（不是崩溃）
- [ ] 错误 Key 时提示鉴权失败
- [ ] 任务进行中「取消」，数秒内停止且不留半截文件
- [ ] 未安装 Ollama 时切到 Ollama 引擎，提示清晰
- [ ] 已安装 Ollama：能自动拉起 `ollama serve` 并检查模型
- [ ] 缺少模型时提示 `ollama pull <模型>`

## 6. 提供商与钥匙串

- [ ] 9 个预设都能填入表单
- [ ] 新建 / 编辑 / 删除提供商
- [ ] 切换当前提供商后立即生效
- [ ] 「测试连接」对错误 Key 返回鉴权失败
- [ ] API Key 存在**钥匙串**里（钥匙串访问.app 搜索 `com.metahumanz.aitrans.provider`），`providers.json` 中无明文
- [ ] 「从旧版导入…」能导入 v1 的 `providers.json`

## 7. 界面

- [ ] 浅色 / 深色模式切换正常
- [ ] 窗口缩放时布局不错位（最小 900×560）
- [ ] 列表滚动流畅（200 条时）
- [ ] `⌘↩` 开始任务，`⌘⇧U` 检查更新
- [ ] 菜单「关于 AITrans」可用

## 8. 更新

- [ ] 无发布版本时提示「仓库还没有发布版本」
- [ ] 已是最新时提示正确
- [ ] 有新版本时显示版本号与更新说明
- [ ] 「下载更新」能把 zip 存到「下载」并定位到文件
- [ ] 「打开下载页」能打开 GitHub Release

## 9. 反馈格式

```text
项目：5. 引擎与网络
环境：macOS 27.2 / Xcode 26
现象：……
日志：~/Library/Logs/AITrans/ 或控制台.app 中 AITrans 的相关输出
```
